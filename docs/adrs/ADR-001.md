Título: ADR-001 - Base de datos
Estado: Aceptado
Fecha: 2026-21-05  
Decisores: MR
Relacionado: proyecto

Contexto
- Se debe determinar el motor de BD a utilizar
- Se requieren transacciones con ACID para los datos médicos, por lo tanto se debería utilizar una BD relacional

Decisión
- Se va a utilizar como BD del proyecto PostgreSQL
- Por el momento es la única BD del proyecto

Alternativas consideradas
- Opción A: SQLite, descartado por escala
- Opción B: PostgreSQL, opción seleccionada

Consecuencias
- Robustez ante la carga de trabajo que podría ser incremental
- Se reconoce cierto riesgo relacionado a performance una vez que crezca el producto
- El equipo por el momento puede utilizar y gestionar esta herramienta

Plan de implementación
- Se debe conectar con Django
- Psycopg (completar versión)

Triggers de revisión
- Latencia en ciertas operaciones como consecuencia de escrituras/lecturas en las tablas
